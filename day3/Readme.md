# Day 03 – Webpage Structure & CSS Layout

## Overview

On Day 3 of my #100DaysOfLearning journey, we focused on understanding how a real-world website is structured and how to turn that understanding into an actual webpage.

## What I Learned

### 1. Understanding Website Structure

We started by looking at **Spotify** and observing how its webpage is structured into different sections and components.

Instead of directly writing code, we first focused on understanding how the different parts of the interface are organized.

### 2. Creating a Wireframe

After studying the structure, we created our own **wireframe** based on what we observed.

The wireframe helped us break the webpage into different sections and visualize the structure before starting the actual implementation.

### 3. Converting the Wireframe into HTML

Once the wireframe was ready, we translated the structure into **HTML** and wrote the code in VS Code.

This helped me understand how a visual structure can be represented using HTML elements.

### 4. Building the Layout with CSS

After creating the HTML structure, we used **CSS** to recreate the layout represented in our wireframe.

We worked on arranging the different sections and elements to match the structure we designed.

## Practical Task

The task was to:

1. Observe and understand the structure of Spotify.
2. Create our own wireframe based on the observed structure.
3. Convert the wireframe into an HTML structure.
4. Use CSS to recreate the layout.

## What I Practiced

- Analyzing a real-world website structure
- Creating a webpage wireframe
- HTML structure and elements
- Writing HTML in VS Code
- CSS layout
- Translating a wireframe into HTML and CSS

## Key Takeaway

The main takeaway from Day 3 was learning to **think about the structure and layout of a webpage before writing the actual code**.

Creating the wireframe first helped me understand how a webpage can be broken down into smaller sections and then built step by step using HTML and CSS.
